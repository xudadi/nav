上线流程 SOP

  1. 备份：保留当前线上 index.html，工程备份文件随本次改动一起存档。
  2. 校验：切到「规则校验」，确认错误数为 0。
  3. 预览：切到「前台预览」，检查层级、顺序、文案、备用链接。
  4. 导出：下载 index.html，用浏览器本地打开，试一次站内搜索（Ctrl+K）。
  5. 发布：替换仓库 / Cloudflare Pages 的 index.html 并提交；观察线上目录与搜索是否正常。
  6. 留痕：把变更清单贴进提交说明；出问题时用下方快照一键回滚。

本次变更清单 相对上次导出 / 首次导入的基线

历史快照 每次导出自动留档，最多 2 版；跨会话长期存档请用工程备份

功能模块划分

模块职责
数据接入导入线上/本地 index.html、工程文件；解析 #mainmenu 嵌套列表为树；保留每个 li 的原始 HTML 片段。
内容编辑分类/链接/说明/分隔线的新增、编辑、删除、改分类、拖拽与按钮排序、批量粘贴录入、全局搜索。
规则引擎必填、URL 合法性、标题与备注长度、重复检测、分类序号、时间自动生成、状态机（草稿/已发布/下线）。
前台预览按线上 DOM 契约渲染，仅显示已发布内容，发布前人工确认。
发布导出字符串级区块替换生成 index.html；输出 JSON 数据源、变更清单、工程备份；快照留档与回滚。
持久化浏览器 localStorage 自动存草稿，工程文件用于跨设备/多人协作与版本管理。

使用方式（首次 5 步）

  1. 点「拉取线上首页」，或点「导入 index.html」选择随附的 nav-index-source.html 快照。
  2. 左侧点分类，右侧表格即显示该分类下的内容；点「+ 新增内容」或行内「编辑」打开右侧表单。
  3. 需要一次录多条时用「批量粘贴录入」，每行 标题 | 链接 | 备注，自动生成草稿。
  4. 用拖拽或 ↑↓ 调整顺序，用「批量改分类」移动归属；改完切到「规则校验」。
  5. 校验无错误 → 「前台预览」确认 → 「导出 index.html」→ 按 SOP 上线。
全程不出现一行 HTML 代码；时间、图标、序号、分类路径均由工具自动补全。

兼容性与后续扩展

  • 零改造：不引入 CMS、数据库、构建步骤，线上仍是原来的静态 index.html。
  • 搜索自动同步：js/find.js 直接从 #mainmenu DOM 建索引，只要结构一致，新条目自动可搜。
  • 样式不变：保留 css/style.css 依赖的 class / notes / bei / split 约定。
  • 保真策略：未编辑的 li 原样输出；编辑过的 li 以自身原始 HTML 为模板改字段，罕见属性不丢失。
  • 可扩展：工程 JSON 带 schemaVersion，新增字段只需扩展节点模型与序列化器；nav-data.json 可直接喂给后端、小程序或搜索服务。
  • 可协作：工程文件 + 变更清单纳入 git，多人分工编辑后合并基线即可。
